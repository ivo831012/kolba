# Колба

Дневник за частни уроци по химия: седмичен график, деца, теми по часовете, програма за материала, бележки и съобщения за Viber.

Приложението е една страница (`index.html`), публикувана с GitHub Pages:
**https://ivo831012.github.io/kolba/**

## Къде се пазят данните

В това хранилище няма данни. Те се пазят във файла `data.json` в **частното** хранилище `kolba-data`. Всяка промяна там остава в историята на commit-ите, така че може да се върне назад.

Всяко устройство пази и копие при себе си. Без интернет приложението работи и качва промените, щом връзката се върне.

## Свързване (еднократно)

1. Създай ключ: <https://github.com/settings/personal-access-tokens/new>
   - **Token name:** Колба
   - **Expiration:** най-дългият възможен срок
   - **Repository access:** Only select repositories → `kolba-data`
   - **Permissions → Repository permissions → Contents:** Read and write
   - Натисни **Generate token** и копирай ключа (`github_pat_…`)
2. Отвори приложението → **Настройки** → „Или въведи данните ръчно“, постави ключа и натисни **Свържи**.
3. На същия екран натисни **Копирай кода за свързване**. С този код всяко друго устройство се свързва с едно поставяне в полето „Код за свързване“.

Ключът има достъп само до `kolba-data` и само до файловете в него. Когато изтече, приложението показва „Ключът не работи“. Тогава създай нов ключ и свържи устройствата отново.

## На телефона като приложение

- **Android (Chrome):** меню ⋮ → „Добавяне към началния екран“
- **iPhone (Safari):** Сподели → „Добави към началния екран“
